# UXsim-Emissions-Extension
This project extends the open-source traffic simulator UXsim by adding a modular emissions modelling framework. The new modules enable UXsim to estimate vehicle emissions alongside traffic flow.

## Commit Messages

We follow Conventional Commits:(https://www.conventionalcommits.org/) - basically giving each commit a header such as `feat:`, `fix:`, `chore:`, `docs:`, etc.

This makes the git history much easier to read.
